# 🌀 台北市颱風假停班停課即時查詢爬蟲 (Taipei Typhoon Holiday Crawler)

讓全台灣的人在 1 秒之內，精準掌握台北市明天是否放颱風假！🚀

本專案直接向 **行政院人事行政總處（DGPA）** 官方資料發起即時爬取，繞過繁瑣廣告與壅塞頁面，以演算法直接解析紅字警告標籤，一鍵輸出清楚判定！

---

## 🌟 特色

- ⚡ **即時精準**：直連行政院人事行政總處最新發布資料庫。
- 🛡️ **連線防護**：內建 SSL 容錯與 User-Agent 模擬，確保不被政府網站連線憑證阻擋。
- 🎯 **智慧判定**：解析 `<font color="#FF0000">` 與停班停課字眼，自動識別是「停止上班上課」還是「照常上班上課」。

---

## 🛠️ 安裝方式

```bash
git clone https://github.com/pppeee861005/taipei-typhoon-crawler.git
cd taipei-typhoon-crawler
pip install requests beautifulsoup4 urllib3
```

---

## 🚀 執行方式

```bash
python main.py
```
